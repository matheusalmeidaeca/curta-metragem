# A Estrela Caída — curta-metragem 2D em Kotlin

Curta de ~82 s desenhado 100% por código (Canvas), com trilha sonora sintetizada e legendas.
Toque na tela = pausar/continuar · arraste a barra de baixo = avançar/voltar · no fim, toque para rever.

APK: aba **Actions** do GitHub → último "Build APK" → Artifacts → `curta-metragem-apk`.
